# Data

`sample/` holds four tiny synthetic phantoms (32^3 voxels) in the BraTS 2020 folder layout. They exercise the I/O and
pre-processing code; they are not medical images. Regenerate them with `python scripts/make_sample_data.py`.

The BraTS 2020 data must be requested from the organisers and are not distributed here (see [docs/data.md](../docs/data.md)).
