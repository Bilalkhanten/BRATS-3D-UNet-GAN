# Thesis builder

Generates the thesis document (`.docx`) from the chapter sources in `content/`, the generators `ch4_*.py`, `ch5_hard.py`,
`appendices.py`, `appx_hard.py` and the run outputs. A reference `.docx` for the page format is required (`--template`) and is not
included. See [docs/thesis.md](../docs/thesis.md).
