# Results

Outputs of the LGG/HGG grade-classification experiments on **synthetic** phantoms (easy: `grade_phantom_a5.*`, hard: `grade_hard_a5.*`).
See [docs/results.md](../docs/results.md) for the file naming and how to read them, and `notebooks/02_explore_grade_results.ipynb`
for an example analysis. BraTS results are produced by the commands of [`RUNBOOK.md`](../RUNBOOK.md) and are not included.
